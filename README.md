# Lab

## Astro Run

Ein Endlosläufer im Stil von Temple Run – nur als Astronaut auf fremden Planeten.
Öffne `astro-run/index.html` im Browser (benötigt Internet für Three.js und die Schriften).

**Steuerung**

| Aktion | Tastatur | Handy |
| --- | --- | --- |
| Spur wechseln / an Ecken abbiegen | ← → oder A D | nach links/rechts wischen |
| Springen | ↑, W oder Leertaste | nach oben wischen |
| Rutschen | ↓ oder S | nach unten wischen |
| Pause | P oder Esc | Pause-Knopf |

**Planeten** (alle 900 m ein neuer, danach geht es wieder von vorn – schneller):
Mond → Mars → Europa → Vulkanus → Xenon. Jeder Planet hat eigene Schwerkraft,
die beeinflusst, wie hoch und lange du springst.

**Gefahren:** Felsbrocken (springen), Monolithen (ausweichen), Laserschranken
(rutschen), Krater (springen) und Kurven am Ende jedes Stegs (rechtzeitig abbiegen).
Der Sauerstoff sinkt ständig – sammle O₂-Tanks. Kristalle geben Punkte, ein
Schild fängt einen Aufprall ab.
